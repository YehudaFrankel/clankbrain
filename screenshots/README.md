# Screenshot Kit

Open each HTML file in a browser, resize to ~700px wide, and screenshot.

| File | Shows |
|------|-------|
| `1-start-session.html` | Memory loading, lessons, Start Session observation |
| `2-plan.html` | Full 8-section plan with Challenge and Rollback |
| `3-regret-guard.html` | Regret guard firing, blocking a bad approach, proposing alternative |
| `4-progress-report.html` | Progress report at session 45 with real numbers |
| `5-end-session.html` | End Session — lessons extracted, memory pushed |

## Tips
- Browser zoom 100%, window width ~740px for best results
- Chrome DevTools → Capture screenshot for pixel-perfect output
- Edit the content in each file to match your real project details
